# Change Log

## [0.2.0] - 2026-05-09

### Support File Explorer View

- Added the ability to use `git mv` from the context menu in File Explorer (meaning you can move multiple files to a folder at once using `git mv`).
- We have enabled the use of `git mv` even if the file currently open in the editor (tab) is an image or similar file.
- We have improved the behavior so that an error message is displayed before opening the dialog if the file is not tracked by Git.
